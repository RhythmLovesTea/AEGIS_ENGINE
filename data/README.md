# AEGIS-Marine — Data Fixtures & Catalog

Storage for local test fixtures, synthetic benchmark datasets, and geospatial reference catalogs.
- `sar/`: Sample Sentinel-1 SAR GRD scenes.
- `ais/`: Historical AIS sample CSV / GeoJSON extracts.
- `metocean/`: CMEMS and ERA5 NetCDF test subsets.
- `synthetic/`: Generated synthetic datasets for offline deterministic testing.
- `geospatial/`: Natural seep catalog and coastal boundary geometries.
